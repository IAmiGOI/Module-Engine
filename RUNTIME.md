# Рантайм Модулей (Раннер) — журнал решений

Заменяет захардкоженный `DEFINITIONS` в [harness/engine-wiring.js](harness/engine-wiring.js)
(ROADMAP 5.5: «НЕ настоящий Раннер»). Слово «расширение» здесь не используется:
оно путается с расширением SillyTavern, внутри которого живёт сам движок.
Говорим «движок» и «Модуль».

## Решения владельца (2026-10-03)

- Делаем всё сразу: загрузка, зависимости, semver, уровни доверия, установка.
- Отдельного файла манифеста нет. Описание Модуля — шапка в его же `index.js`.
- Встроенные Модули — из папки `modules/*`. Остальные — из репозиториев.
- Подпись и шифрованный ключ уровня `community` — ОТЛОЖЕНЫ. Пока внешним Модулям
  выдаются только уровни `scanned-safe` / `scanned-unsafe` по результату скана.
- Каталог: одна ссылка на репозиторий с подтверждёнными Модулями (папка на
  Модуль) + список ссылок на GitHub на сторонние (Third-Party) Модули.

## Шапка Модуля

Первым в `index.js` идёт блок-комментарий `/*@module ... */`, строки `ключ: значение`:

```
/*@module
id: community.dice
title: Dice
description: Rolls dice on request.
version: 1.2.0
engine: ^0.2
requires: module.tracker@^1.0, core.map@>=0.3
rights: tracking.poll, ui.notify
network: false
*/
```

- Читается как ТЕКСТ, без исполнения: чужой Модуль можно проверить, не запуская.
- Хэш и скан считаются по тому же тексту, который потом исполняется.
- `id`, `version` — обязательны. `engine` (диапазон версии движка), `requires`,
  `rights`, `network` — по умолчанию пусто / `false`.
- Для встроенных `rights` — запрашиваемый набор; уровень `official` даёт движок.
  Для внешних `rights` — лишь ЗАПРОС: итоговые права решает уровень доверия.

## Импорты внешнего Модуля

Только `stme:<путь>` (например `stme:ui/tree`, `stme:widgets`), движок
подменяет их на реальные адреса при подготовке исходника. Любой другой импорт
(`http(s):`, `data:`, относительный путь наружу) — нарушение скана.
Исполняется ровно тот текст, что был хэширован и просканирован (Blob URL),
чтобы между проверкой и запуском ничего не подменилось.

## Честное ограничение

Песочницы нет: JS внешнего Модуля живёт в той же странице, что и ST.
Защита — права через Гейт, хэш, скан и карантин, не изоляция.

## Каталог

Репозиторий каталога (GitHub) устроен так — формат выбран исполнителем, владелец сказал «давай сам»:

```
modules/<имя>/index.js    подтверждённые Модули, по папке на Модуль, ОДНИМ файлом
third-party.txt           по ссылке на GitHub в строке, # — комментарий
```

Ссылка на сторонний Модуль: `owner/repo`, URL репозитория, `…/tree/<ref>/<dir>` (берётся `<dir>/index.js`) или `…/blob/<ref>/<файл>.js`.
Адрес репозитория каталога пользователь вводит сам (запоминается в `core.runner/catalogRepository`); по умолчанию —
`IAmiGOI/Module-Engine-Modules` (https://github.com/IAmiGOI/Module-Engine-Modules; там README с правилами и пример `modules/hello`).

## Установка и запуск

- **Предпросмотр ничего не ставит**: скачивает текст, разбирает шапку, сканирует, считает SHA-256 и показывает уровень доверия,
  запрошенные права, запрос сети, находки скана и «заменяет версию X». Только потом «Install».
- **Исполнение**: установленный Модуль хранится вместе с исходником (запуск не требует сети); при КАЖДОМ запуске он разбирается
  и сканируется заново тем же `analyzeExternalModule()`. Включает его пользователь отдельно.
- **Имя**: внешний id обязан начинаться с `community.`; `module.*` принадлежит встроенным.
- **Размер**: исходник до 512 КБ.
- **Сеть** из шапки только ЗАПРАШИВАЕТСЯ и сама не выдаётся (в UI выдача пока не предусмотрена).

## Карантин

- Внешний Модуль регистрируется с `quarantineOnViolation`: любой отказ Гейта (контракт вне прав, `http.request` без сетевого права)
  → карантин в Ядре прав (в сессии необратим) и запись `{id, hash, contract, at}` в `core.runner/quarantinedModules`.
- Встроенные карантином НЕ карались и не караются: они иногда нащупывают чужие контракты, молчаливый отказ — прежнее поведение.
- Карантин привязан к **id**, не к хэшу: исправленная версия под тем же именем его не снимает. Снимает только пользователь
  («Allow again» → `rights.unquarantine()`). Рекомендация и компромисс: к хэшу привязывать нельзя — автору достаточно поменять байт.
- Пока Модуль в карантине, он не загружается при запуске, в предпросмотре отказывается и показывается в «Could not load».
