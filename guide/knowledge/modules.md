Modules are switched on and off in [Modules](stme:card:modules); each one's settings appear there once it is on. Module ids for actions: Tracker — module.tracker, RP Time — module.time, Notebook — module.notebook, Secrets — module.secrets, Post-Turn Processor — module.postprocess, Music — module.music, Scene Painter — module.scenePainter, Speaker Colors — module.speakerColors, Map — module.map.
Good first modules: Tracker (see values like health or mood update by themselves) and RP Time (in-world clock). Most modules need a working model connection.
