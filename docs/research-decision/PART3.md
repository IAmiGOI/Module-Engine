# Директор, часть 3: без Prompt Manager, директор всегда включён, встроенные промпты

Части 1–2 готовы (`REPORT.md`). Владелец принял новые решения (`DIRECTOR-SPEC.md`, разделы от 2026-11-02):
1. **Prompt Manager удаляется целиком.** Вместо него два раздела — директора и прозаика. В каждом **один кастомный блок** — свой текст пользователя:
   - у директора он встаёт на глубину **2 цикла**;
   - у прозаика — на глубину **@5**.

   Лорбук и прочее не настраиваются.
2. **Директор всегда включён.** Выключателя и запасного пути через сборку ST нет.
3. **Лорбук — только у директора.** Прозаик его не видит.
4. **Действия гида Mea с пресетами PM уходят**, замены пока нет.

Встроенные промпты написаны: **`PROMPTS.md`. Переносить в код дословно**, смысл без владельца не менять.

Работа идёт в той же ветке `research/decision`. **Правило частей 1–2 «выключено = как сейчас» больше не действует.** Тесты «байт в байт при выключенном ядре» удаляются вместе с выключателем.

## Блоки (коммит на каждый блок с итогом, запись в `LOG.md`)

### f0. Разведка
- Полная карта зависимостей от PM: каждый вызов `promptManager.*`, каждый импорт `pm-*`, права, UI, бэкап, синхронизация, гид, документация. Записать в `LOG.md` списком «удалить / заменить / оставить».
- Как теперь выглядит ход без PM: ST сам собирает своё тело, директор заменяет его телом прозаика на `generation.payload`. Проверить, что ничего не ждёт этапа `prompt-manager:rewrite` (`needs` в `decision:rewrite`).
- **Хранилище больших данных директора.** Сейчас лог, банк и библиотека лежат в метаданных чата: до ~2,4 МБ лога и ~0,25 МБ банка на персонажа, а ST перезаписывает файл чата целиком при каждом сохранении.
  - Замер: сколько стоит сохранение чата с метаданными 1 / 3 / 6 МБ (тело запроса сохранения, время записи) — хотя бы на синтетике без ST.
  - Предложить решение: остаться в метаданных или вынести лог, архив и банк в отдельное хранилище с ключом по чату. Тогда учесть бэкап и синхронизацию: данные директора не должны теряться при восстановлении и не должны путаться между чатами.
- **Лорбук для директора:** что подключённые книги отдают через Ядро лорбука. Выбрать с оглядкой на кеш префикса:
  - маленькую книгу — целиком в стабильную часть контекста;
  - большую — постоянные записи в контекст плюс инструмент поиска по книге.

### f1. Удаление Prompt Manager
- Удалить PM, Guided CoT, лорбук-движок PM, панель, сервисы, действия гида с пресетами, их тесты и регистрацию.
- Тест карточки (`card-test.js`) перевести на связку директор → прозаик. Тестовые ходы идут через неё, как в игре.
- Бэкап и синхронизация: убрать пресеты PM из состава. Старые бэкапы с ними должны восстанавливаться без ошибки — лишнее игнорируется.
- Вклады модулей идут запасным путём `deliverToPrompt`. Убедиться, что ни один модуль не упал из-за отсутствия PM.
- Документацию поправить: PM удалён, ссылки на него — в историю.

### f2. Директор всегда включён
- Убрать `enabled`, выключатель в карточке, запасной путь, ветки «если ядро выключено», легаси-JSON-ответ части 1.
- Прозаик получает только Character Notes. Блоки о персонаже из части 1 убрать: заметки их заменили.
- Воркер директора не настроен (или формат не `openai`):
  - генерация не отправляется;
  - понятное уведомление со ссылкой на карточку директора;
  - прогон закрывается правильно, ничего не виснет.
- Тесты: генерация без воркера директора не уходит и даёт уведомление; ход с настроенным воркером работает как в части 2.

### f3. Встроенные промпты и кастомные блоки
- Тексты из `PROMPTS.md` — дословно, в отдельный файл библиотеки (например, `libraries/core/decision-prompts.js`). Подстановки `{{…}}` — функцией, а не склейкой по месту.
- Описания инструментов (`description` в схемах) сверить с `PROMPTS.md`. Убрать устаревшие фразы вроде «while the core is on».
- **Два раздела в карточке:** «Director prompt» и «Writer prompt», по одному многострочному полю. Больше ничего.
- **Размещение:**
  - текст директора — отдельным system-сообщением на глубине 2 цикла от конца лога (перед последними двумя циклами);
  - текст прозаика — на глубине @5 (пять сообщений от конца истории);
  - пустое поле — блока нет.
- Тесты: позиция блока у директора при 0 / 1 / 2 / 5 циклах; позиция у прозаика при истории короче 5 и длиннее; пустой блок не вставляется.
- Замер кеша (`pm-cache.js` удаляется вместе с PM — нужную функцию перенести в `decision-*`): насколько меньше общий префикс директора с блоком на глубине 2 цикла по сравнению с блоком в начале. Цифры в `LOG.md`.
